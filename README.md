# KomorebiSDR

> *Named after "Komorebi" (木漏れ日) — the sunlight filtering through trees.*

A calm, beautiful radio receiver for RTL-SDR. Plug in your dongle, launch the app, and enjoy clear radio broadcasts without complicated controls or radio jargon.

![KomorebiSDR Screenshot](assets/screenshot.png)

## Features

- **Effortless Listening**: Plug in your device and start listening right away. It finds clear stations automatically.
- **Calm Interface**: A clean, distraction-free visual display designed for everyday background listening.
- **Clear Sound**: Automatically reduces background hiss and balances volume for comfortable listening.
- **FM, AM & Shortwave**: Easily switch between local music stations, talk radio, and distant overseas broadcasts.

## Quick Start

```bash
git clone https://github.com/ootake0914-dotcom/KomorebiSDR.git
cd KomorebiSDR
pip install -r requirements.txt
python main.py
```
