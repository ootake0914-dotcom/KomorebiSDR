4. 画面構成（2層化）

  • ホーム：局名・周波数・ダイヤル・電源・音量・お気に入り・受信状態
  • 詳細パネル：現行UI相当（数値・ノイズ低減・感度・スキャン等）を全格納
  • 初回：3ステップ案内（挿す→電源→ダイヤル）＋地域プリセット自動提示

5. 実装メモ（開発者向け）

  • 既存pygame GUIは「詳細パネル」として温存し、ホーム画面を新レイヤーとして追加する
  • ダイヤル操作→既存 `_tune()` に接続。局名解決はプリセット＋RDS
  • 受信状態文（良好／やや弱い／弱い）は S-meter・lock・NR量から生成する関数を新設
  • 製品表記は KOMOREBI Radio を推奨（SDRの語を表に出さない）
